PURPOSE
  Determine the effective elastic anisotropy of WAAM-manufactured steels
  (316L austenite, 17-4PH martensite) from measured EBSD microstructures:
    EBSD  ->  statistically-equivalent 3D polycrystal (Neper)  ->  mesh  ->
    per-grain anisotropic linear-elastic FE homogenization + uniaxial test
    (dolfinx)  ->  effective stiffness Chom and directional E-modulus.

4. HOW TO RUN (end to end)
--------------------------------------------------------------------------------
  STEP 1 — meshes (Neper/Gmsh container, from Neper/ on the host)
    docker compose up -d --build
    docker compose exec ubuntu_custom bash -c \
      "CLEAN=1 bash /data/04_anisotropy_waam/neper_pipeline/run_pipeline.sh"
    (test first with FAST=1; real optimized run takes longer.)
    Produces: waam_<MAT>_n300.xdmf/.h5, spec_<MAT>_V/H/45deg.*, spec_combined_V.*
    each with grain_ori_*.txt.

  STEP 2 — stage meshes for dolfinx (HOST; both trees visible)
    cd .../dolfinx_alex/shared/scripts/069-waam-polycrystal-anisotropy
    python3 prepare_inputs.py --rve 316L 17-4PH --n 300
    python3 prepare_inputs.py --specimens 316L 17-4PH

  STEP 3 — edit config.json (single-crystal constants) if needed.

  STEP 4 — FE computations (dolfinx container, from dolfinx_alex/)
    docker compose up -d --build
    docker compose exec alex-dolfinx bash -c \
      "cd /home/scripts/069-waam-polycrystal-anisotropy && bash run_fem.sh"
    (NP=8 for MPI; HOMOG=0 or UNIAXIAL=0 to run only one set.)

  STEP 5 — evaluation + report
    python3 evaluation.py                 # figures + summary tables
    python3 engineering_constants.py      # orthotropic E_i/nu_ij/G_ij (Table 3)
    (report PDF built from report.md via LaTeX/xelatex:
       cd report && bash build_report.sh
       # or: pandoc report.md -o WAAM_anisotropy_report.pdf --pdf-engine=xelatex
       # figures/tables auto-numbered via {#fig:label}/\label + \ref -> no manual
       # renumbering. Needs TeXLive(xelatex) + DejaVu fonts. docx is retired.)

5. KEY MODELING DECISIONS (see README.md + the report for full rationale)
--------------------------------------------------------------------------------
  - SECTIONING GEOMETRY (confirmed 2026-07): every EBSD polish plane is a
    cross-section PERPENDICULAR to the tensile-specimen axis (specimens: V||build,
    H _|_ build i.e. ||weld, 45deg). Therefore:
      * V-section _|_ build  -> plane (weld x wall-normal); aspect 3.18 =
        weld/wall-normal; its NORMAL is the build direction.
      * H-section _|_ weld   -> plane (build x wall-normal); aspect 3.41 =
        build/wall-normal.
    Independent 45deg check: this geometry predicts the 45deg aspect 3.29
    (measured 2.60); the earlier "V=wall face" assumption predicted 4.60. So the
    perpendicular-section geometry is data-supported.
  - 316L: single-phase FCC, ORTHOTROPIC grains. k_build=3.41 (build/wall-normal,
    from HORIZONTAL section, coherent R=0.87), k_inplane=3.18 (weld/wall-normal,
    from VERTICAL section, R=0.73). Wall-normal is the base (=1). Grain shape
    L_z:L_x:L_y ~ 3.4:3.2:1 (plate-like; build~weld, NOT strongly columnar).
    Transform scale(k_inplane,1,k_build) = scale(3.18,1,3.41); frame x=weld,
    y=wall-normal, z=build. RVE box ~3690 x 1160 x 3956 um at n=500 (~8
    grains/direction). TEXTURE FRAME: orientations sampled from the V-section;
    build = V-section NORMAL -> z, weld = V-section in-plane axis -> x. The section
    -> axis mapping is configurable in materials.py (k_build_section,
    k_inplane_section, build_normal_section). Shape applied consistently to RVE
    (02 scale_xyz), bars (07) and combined bar (08) via
    params.neper.scale_build_frame = [k_build,k_inplane,1] (rotated by alpha in 07).
  - 17-4PH: phases pooled (per grain crystal kept), EQUIAXED (k=1) because the
    grain elongation is directionally incoherent (R=0.08) — a global stretch
    would fabricate anisotropy. Size via equivalent diameter, min_points=50,
    and cv_cap=0.8 (measured CV~1.4) for the Neper target distribution only
    (median preserved; does not affect effective anisotropy).
  - Transition (combined bar) is a single homogeneous grain (n=1).
  - Per-grain stiffness: C_sample = M(g) C_crystal M(g)^T (6x6 stress Bond
    matrix, Voigt order xx,yy,zz,yz,xz,xy, engineering shear).
  - Homogenization = KUBC (upper/stiff bound). Uniaxial = symmetric BC + free
    lateral faces (apparent E in load direction).
  - Units: mesh in um, single-crystal C in GPa -> moduli in GPa.

6. GOTCHAS
--------------------------------------------------------------------------------
  - Two containers, separate mounts: dolfinx sees only shared/; always run
    prepare_inputs.py after (re)generating meshes.
  - dolfinx is v0.7.3: use ufl.VectorElement/TensorElement + dlfx.fem.FunctionSpace
    (NOT the 0.8 functionspace()/("Lagrange",..) tuple API).
  - Reading grain tags in dolfinx: read_mesh(name="Grid") + read_meshtags(name=
    "Grid") — works because the meshio XDMF has a single "grain" cell attribute.
  - Neper -morpho optimization: strict val criteria never terminate here; use
    val=1e-2||itermax=... (already the defaults). CV cap keeps 17-4PH tractable.
  - Neper -M can SIGABRT on 3D meshing; 08/07 retry at coarser rcl and (08) fall
    back to Voronoi. Combined bar auto-regenerates region if the cached grain
    count no longer matches the fit.
  - Results (Chom/Emodul) are in GPa and scale with config.json — placeholders!
  - 17-4PH uniaxial bars are thin/flat -> more statistical scatter than the RVE.
